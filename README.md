# 공지·입시 감시 대시보드

> **웹 버전**(PC를 켜 두지 않아도 되고 휴대폰에서도 보는 방식)은 `WEB_SETUP.md` 를 따라 설정한다.
> 아래는 내 PC에서 돌리는 방식(app.py)이다. 둘 다 같은 config.yaml 을 쓴다.

학교 공지와 국내외 대학원 입시 페이지를 한 화면에서 보는 로컬 웹 대시보드.

## 설치 (최초 1회)
압축을 푼 폴더에서:
```
pip install requests beautifulsoup4 pyyaml openpyxl
```

## 실행
```
python app.py
```
또는 Windows 에서 `실행.bat` 더블클릭.
브라우저가 http://127.0.0.1:8765 를 자동으로 연다. 창을 닫아도 서버는 켜져 있고, 터미널에서 Ctrl+C 로 끈다.

- **지금 확인**: 등록된 모든 대상을 바로 확인한다 (약 1분, 사이트당 2초 간격).
- **자동 확인**: 켜 둔 동안 `config.yaml`의 `auto_check_hours`(기본 6시간)마다 스스로 확인한다.
- **처음 확인**: 지금 올라와 있는 글은 '읽음'으로 쌓인다. 그 뒤 새로 올라온 글에만 빨간 삼각형이 붙는다.
- **페이지 변경 감지** 대상(교토대·도호쿠대·독일·싱가포르 등)은 첫 확인 때 기준만 저장하고, 다음 확인부터 새로 생긴 문장을 보여준다.
- 제목을 누르면 원문이 새 탭으로 열리고 읽음 처리된다. ☆로 별표, 왼쪽 아래에서 엑셀로 내보내기.

## 폴더 구성
```
app.py            웹 대시보드 서버
crawler.py        크롤링 엔진 (python crawler.py 로 화면 없이도 실행 가능)
config.yaml       감시 대상 목록
static/index.html 대시보드 화면
notices.db        수집 결과 (자동 생성)
page_snapshots/   페이지 변경 감지용 사본 (자동 생성)
```
처음부터 다시 받고 싶으면 `notices.db`와 `page_snapshots/`를 지운다.

## 감시 대상 추가·수정·삭제
대시보드 위쪽 **감시 대상 관리** 탭에서 한다. 서버를 다시 켤 필요 없이 다음 확인부터 반영된다.

- **켜기/끄기**: 스위치. 잠시 쉬게 할 때는 삭제보다 이쪽이 낫다.
- **새 대상 추가** 순서
  1. 이름, 분류, 주소를 넣는다. 메모에 넣은 이유를 적어 둔다.
  2. 방식을 고른다.
     - 게시판: 글 목록이 있는 페이지. **구조 자동 추정**을 누르면 글 한 줄·제목 링크를 찾아 채우고 바로 미리보기를 보여준다.
     - 페이지 변경 감지: 게시판이 없는 안내 페이지. **미리보기**로 본문이 잘 잡히는지만 본다.
  3. 미리보기에서 제목·날짜·링크가 맞으면 **저장**.
- **수정**: 이름을 바꿔도 그동안 모은 글은 새 이름으로 이어진다.
- **삭제**: '그동안 모은 글도 지운다'를 체크하면 목록에서도 사라진다.
- **↑ ↓**: 같은 화면에서 보이는 순서.
- **제외한 곳 메모**: 뺀 곳과 이유를 적어 두는 칸.
- robots.txt가 수집을 금지한 사이트는 미리보기 단계에서 막힌다.
- 저장할 때마다 바로 이전 설정이 `config.yaml.bak`에 남는다. 잘못 지웠으면 이 파일 이름을 `config.yaml`로 바꾸면 된다.

## config.yaml 항목 (직접 고칠 때만 참고)
| 항목 | 뜻 |
|---|---|
| type | board(게시판) / watch(페이지 변경 감지) |
| list_url / url | 게시판 목록 주소({page} = 페이지 번호) / 감시할 페이지 주소 |
| row_selector, title_selector | 글 한 줄, 그 안의 제목 링크 (CSS 선택자) |
| title_text_selector, date_selector, remove_in_title | 링크 안 제목 부분, 날짜 칸, 제목에서 지울 꼬리표 |
| category_selector, categories | 말머리 칸과 수집할 말머리 |
| link_regex, link_template | 링크가 javascript:view('123') 형태일 때 상세 주소 만드는 규칙 |
| include, exclude | 제목 키워드 필터 |
| content_selector, keywords | (watch) 본문 영역, 이 단어가 든 변경만 알림 |
| enabled, note | 켜짐 여부, 메모 |

## 지키는 원칙
매번 robots.txt 확인, 요청 간 2초 대기, 크롤러임을 밝히는 User-Agent, 로그인·우회·비공개 API 호출 없음, 개인 용도로만 사용.
서버는 내 PC(127.0.0.1)에서만 열린다.
