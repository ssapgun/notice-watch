      감시 대상별 상태
      분류대상방식최종 성공상태
      연결 설정이 필요하다. 보기는 되지만, 추가·수정·삭제는 '연결 설정' 탭에서 GitHub 토큰을 넣어야 저장된다.

      저장하면 GitHub 저장소의 config.yaml 이 바뀌고, 바로 확인이 한 번 돈다. 결과는 2~5분 뒤 '공지 보기'와 상태표에 나온다.

      제외한 곳 메모

      GitHub 연결

      보기만 할 때는 필요 없다. '지금 확인'과 감시 대상 수정을 쓰려면 이 저장소 전용 토큰(Fine-grained token)을 넣는다. 토큰은 이 기기의 브라우저에만 저장되고 GitHub 외의 곳으로 보내지 않는다. 공용 PC에서는 넣지 말 것.
